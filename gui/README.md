# WeChatMsg GUI 使用说明

## 概述

WeChatMsg GUI是一个用户友好的图形界面，用于微信聊天记录的解析和导出。它提供了直观的操作界面，支持微信4.0和3.x版本，可以导出多种格式的聊天记录。

## 主要特性

- 🔍 **自动扫描微信账户**: 自动检测系统中运行的微信账户
- 🔐 **安全解密**: 自动获取密钥并解密微信数据库
- 👥 **联系人管理**: 查看和管理所有联系人，支持群聊和私聊
- 📤 **多格式导出**: 支持HTML、TXT、CSV、DOCX、Markdown、Excel等格式
- ⚙️ **灵活配置**: 可配置时间范围、消息类型过滤等
- 🎨 **现代化界面**: 基于Tkinter的现代化用户界面
- 📊 **实时状态**: 实时显示处理进度和状态信息

## 系统要求

- **操作系统**: Windows (仅支持Windows)
- **Python版本**: Python 3.9+
- **依赖库**: 参见requirements.txt
- **其他要求**: 微信客户端需要正在运行

## 安装和启动

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动GUI

方式一（推荐）：使用根目录快捷启动脚本
```bash
python start_gui.py
```

方式二：进入gui目录启动
```bash
cd gui
python run_gui.py
```

方式三：直接运行主程序
```bash
python gui/gui_main.py
```

> **Windows用户注意**: 如果您的Python环境使用 `py` 命令，请将上述命令中的 `python` 替换为 `py`。

## 使用指南

### 第一步：解密数据库

1. **启动微信**: 确保微信客户端正在运行并已登录
2. **扫描账户**: 在"解密数据库"标签页点击"扫描微信账户"
3. **选择账户**: 从列表中选择要解密的微信账户
4. **开始解密**: 点击"开始解密"按钮，等待解密完成

### 第二步：查看联系人

1. **自动加载**: 解密成功后会自动切换到"联系人管理"标签页
2. **浏览联系人**: 查看所有联系人，包括群聊和私聊
3. **搜索功能**: 使用搜索框快速查找特定联系人
4. **选择联系人**: 勾选要导出的联系人

### 第三步：导出聊天记录

1. **配置导出**: 在"导出聊天记录"标签页配置导出参数
   - 选择导出格式
   - 设置输出目录
   - 配置时间范围（可选）
   - 选择消息类型（可选）
2. **添加任务**: 可以添加选中的联系人或指定特定微信ID
3. **开始导出**: 点击"开始导出"按钮执行导出任务

## 导出格式说明

| 格式 | 描述 | 特点 |
|------|------|------|
| HTML | 网页格式 | 支持图片、表情，样式美观 |
| TXT | 纯文本格式 | 文本内容，体积小 |
| CSV | 表格格式 | 可用Excel打开，便于分析 |
| DOCX | Word文档 | 支持富文本格式 |
| Markdown | 标记语言 | 便于编辑和转换 |
| XLSX | Excel表格 | 结构化数据，便于统计 |
| AI_TXT | AI分析格式 | 包含AI分析结果 |

## 配置选项

### 基本设置

- **默认导出格式**: 设置默认的导出文件格式
- **默认输出目录**: 设置导出文件的默认保存位置
- **最大线程数**: 设置并发处理的最大线程数
- **自动检测版本**: 是否自动检测微信版本

### 时间范围

可以设置导出消息的时间范围：
- **开始时间**: 导出的起始时间
- **结束时间**: 导出的结束时间

### 消息类型过滤

可以选择要导出的消息类型：
- 文本消息
- 图片消息
- 语音消息
- 视频消息
- 表情包
- 文件消息
- 链接消息
- 位置消息

## 故障排除

### 常见问题

1. **无法扫描微信账户**
   - 确保微信客户端正在运行
   - 尝试重启微信客户端
   - 检查是否有管理员权限

2. **解密失败**
   - 确保微信客户端正在运行
   - 检查磁盘空间是否足够
   - 尝试重启后再次解密

3. **加载联系人失败**
   - 确认数据库已成功解密
   - 检查解密后的数据库文件是否存在
   - 尝试重新解密数据库

4. **导出失败**
   - 检查输出目录是否存在写入权限
   - 确认磁盘空间充足
   - 检查联系人ID是否正确

### 错误代码

- **E001**: 微信进程未找到
- **E002**: 获取密钥失败
- **E003**: 解密过程中出错
- **E004**: 数据库连接失败
- **E005**: 联系人加载失败
- **E006**: 导出过程中出错
